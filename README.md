# AI 이메일 전문가

받은 비즈니스 이메일과 답장에 꼭 넣을 핵심 내용을 입력하면, 영문 답장과 한글 대조본을 함께 만들어 주는 웹 앱입니다.

## 주요 기능
- 영문 답장 + 한글 대조본 동시 생성 (단락 구성 동일)
- 핵심 정보(일정·수치·요청사항) 굵은 글씨 강조
- 말투 선택: 격식 / 정중·부드럽게 / 간결하게 / 단호하게
- 서명 저장 (브라우저 로컬 저장)
- 서식 유지 복사 (Outlook, Gmail 붙여넣기 시 굵은 글씨 유지)
- 한쪽을 수정하면 다른 쪽에 반영하는 번역 갱신 버튼

## 실행 환경
이 앱은 Claude(claude.ai) 아티팩트 런타임의 AI 호출 기능을 사용합니다.
claude.ai에서 열었을 때 AI 작성 기능이 동작하며, 그 외 환경(GitHub Pages 등)에서는 화면만 표시되고 작성 기능은 비활성화됩니다.
