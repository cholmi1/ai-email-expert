# AI 이메일 전문가

받은 비즈니스 이메일과 답장에 꼭 넣을 핵심 내용을 입력하면, 영문 답장과 한글 대조본을 함께 만들어 주는 웹 앱입니다. Anthropic Claude API를 사용합니다.

## 주요 기능
- 영문 답장 + 한글 대조본 동시 생성 (단락 구성 동일)
- 핵심 정보(일정·수치·요청사항) 굵은 글씨 강조
- 말투 선택: 격식 / 정중·부드럽게 / 간결하게 / 단호하게
- 서명 저장, 서식 유지 복사 (Outlook·Gmail 붙여넣기 시 굵은 글씨 유지)
- 한쪽을 수정하면 다른 쪽에 반영하는 번역 갱신 버튼
- 모델 선택: Sonnet 5.5(권장) / Opus 5.5 / Haiku 5.5

## 사용 방법
1. https://console.anthropic.com 에서 API 키를 발급하고 크레딧을 충전합니다.
2. 앱 상단의 **API 키 설정**을 열어 키를 붙여넣고 **저장**을 누릅니다.
3. 받은 메일과 핵심 내용을 입력하고 **답장 만들기**를 누릅니다.

## GitHub Pages로 배포하기
저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 지정하고 저장하면
몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속할 수 있습니다.

## 보안 안내
- API 키는 저장소에 들어 있지 않으며, 사용자가 입력한 키는 해당 브라우저의 localStorage에만 저장됩니다.
- 키는 브라우저에서 Anthropic API로 직접 전송되며 다른 서버를 거치지 않습니다.
- 공용 PC에서는 사용 후 **삭제** 버튼으로 키를 지워 주세요.
- Anthropic 콘솔에서 월 사용 한도(Spend limit)를 설정해 두시길 권장합니다.
